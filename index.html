Sincronização com Google Sheets

Conecta este aplicativo a uma planilha exclusiva do controle financeiro. Depois de configurar o endpoint, podes sincronizar os lançamentos entre dispositivos.

A primeira configuração exige criar uma planilha e publicar o script como aplicativo da Web. Não coloques senhas nem dados bancários neste campo.

Como configurar a planilha (uma vez)
  1. Cria uma planilha Google nova, exclusiva para o controle financeiro.
  2. Na planilha, abre Extensões → Apps Script.
  3. Cola o conteúdo do arquivo Google_Apps_Script.gs incluído no pacote atualizado e salva.
  4. Clica em Implantar → Nova implantação, escolhe Aplicativo da Web, executar como tu e acesso qualquer pessoa. Confirma e autoriza.
  5. Copia a URL terminada em /exec para o campo acima e clica em Salvar endereço.
  6. Faz um backup local antes da primeira sincronização. Usa Enviar meus dados para a nuvem para iniciar a planilha com teus dados atuais.

A URL do aplicativo da Web funciona como endereço de acesso à API. Compartilha-a apenas com quem deve acessar os dados financeiros.

Os dados ficam neste navegador e podem ser sincronizados com a planilha Google configurada. Faz backups regularmente.
